RAG as Context Engineering

Module 8, Lecture 8.1 | Retrieval-Augmented Generation (RAG)

Modules 4 and 7 managed context after it accumulated; this lecture asks where useful information comes from in the first place. A model does not know recent events, private knowledge such as a codebase or a company's product manuals, or high-precision facts it saw only in compressed form during training. Putting everything into the context fails, because the window is finite, every token is paid for on every call, and quality degrades with length. Retrieval-augmented generation (RAG) supplies only what the current query needs: retrieve relevant information, augment the context with it, and generate. The model itself is unchanged; only its context is. The lecture separates the setup phase, which prepares a knowledge source for retrieval, from the query phase that runs on every request, and compares two ways to wire retrieval: the developer's code retrieves before the model call (classic RAG), or the model calls a search tool, as Claude Code does with glob and grep. It contrasts RAG with fine-tuning, which changes model weights and suits style and format, and closes on the framing for the rest of Module 8: RAG is a category, and vector search is one implementation alongside web search, database queries, file reads, and API calls.

Additional Resources

  • Lecture slides
  • Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks — Lewis et al., NeurIPS 2020. The original RAG paper, which introduced the term and the retrieve-then-generate pattern.
  • Effective context engineering for AI agents — Anthropic, 2025. Covers just-in-time retrieval and agentic search versus pre-computed embeddings, and describes Claude Code's hybrid approach: CLAUDE.md loaded up front, glob and grep at runtime.
  • Claude Code: Anthropic's Agent in Your Terminal — Latent Space podcast, 2025, with Boris Cherny and Cat Wu of the Claude Code team. Explains why the team moved from indexed RAG to agentic search, and the latency and token costs they accepted.
  • Fine-Tuning or Retrieval? Comparing Knowledge Injection in LLMs — Ovadia et al., 2023. Finds that RAG consistently outperforms unsupervised fine-tuning for adding factual knowledge, including knowledge the model has never seen.
  • Retrieval-Augmented Generation for Large Language Models: A Survey — Gao et al., 2023. A widely cited survey of naive, advanced, and modular RAG; a map of the field beyond this module.
  • ReAct: Synergizing Reasoning and Acting in Language Models — Yao et al., ICLR 2023. The model calls a Wikipedia API as an action while it reasons, an early form of retrieval as a tool.
